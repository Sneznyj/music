Аккорд C на гитаре

До, мажорный аккорд. Ноты: C (до), E (ми), G (соль).

Основной вариант
  • Безымянный — 3-й лад 5-й струны.
  • Средний — 2-й лад 4-й струны.
  • Указательный — 1-й лад 2-й струны.
  • Открытые струны: 3, 1.
  • Не играть: 6.
Вариант 2
  • Указательный лежит поперёк струн с 5-й по 1-ю на 3-м ладу (баррэ).
  • Безымянный — 5-й лад 4, 3, 2-й струн.
  • Не играть: 6.
Вариант 3
  • Указательный лежит поперёк струн с 6-й по 1-ю на 8-м ладу (баррэ).
  • Безымянный — 10-й лад 5-й струны.
  • Мизинец — 10-й лад 4-й струны.
  • Средний — 9-й лад 3-й струны.

Нажмите на схему, чтобы услышать аккорд. Оранжевые точки — тоника, нота до.
