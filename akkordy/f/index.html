Аккорд F на гитаре

Фа, мажорный аккорд. Ноты: F (фа), A (ля), C (до).

Основной вариант
  • Указательный лежит поперёк струн с 6-й по 1-ю на 1-м ладу (баррэ).
  • Безымянный — 3-й лад 5-й струны.
  • Мизинец — 3-й лад 4-й струны.
  • Средний — 2-й лад 3-й струны.
Вариант 2
  • Безымянный — 3-й лад 4-й струны.
  • Средний — 2-й лад 3-й струны.
  • Указательный — 1-й лад 2, 1-й струн.
  • Не играть: 6, 5.
Вариант 3
  • Указательный лежит поперёк струн с 5-й по 1-ю на 8-м ладу (баррэ).
  • Безымянный — 10-й лад 4, 3, 2-й струн.
  • Не играть: 6.

Нажмите на схему, чтобы услышать аккорд. Голубые точки — тоника, нота фа.
