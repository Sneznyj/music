Аккорд G на гитаре

Соль, мажорный аккорд. Ноты: G (соль), B (си), D (ре).

Основной вариант
  • Средний — 3-й лад 6-й струны.
  • Указательный — 2-й лад 5-й струны.
  • Безымянный — 3-й лад 1-й струны.
  • Открытые струны: 4, 3, 2.
Вариант 2
  • Средний — 3-й лад 6-й струны.
  • Указательный — 2-й лад 5-й струны.
  • Безымянный — 3-й лад 2-й струны.
  • Мизинец — 3-й лад 1-й струны.
  • Открытые струны: 4, 3.
Вариант 3
  • Указательный лежит поперёк струн с 6-й по 1-ю на 3-м ладу (баррэ).
  • Безымянный — 5-й лад 5-й струны.
  • Мизинец — 5-й лад 4-й струны.
  • Средний — 4-й лад 3-й струны.
Вариант 4
  • Указательный лежит поперёк струн с 5-й по 1-ю на 10-м ладу (баррэ).
  • Безымянный — 12-й лад 4, 3, 2-й струн.
  • Не играть: 6.

Нажмите на схему, чтобы услышать аккорд. Голубые точки — тоника, нота соль.
