Аккорд Dm на гитаре

Ре, минорный аккорд. Ноты: D (ре), F (фа), A (ля).

Основной вариант
  • Средний — 2-й лад 3-й струны.
  • Безымянный — 3-й лад 2-й струны.
  • Указательный — 1-й лад 1-й струны.
  • Открытые струны: 4.
  • Не играть: 6, 5.
Вариант 2
  • Указательный лежит поперёк струн с 5-й по 1-ю на 5-м ладу (баррэ).
  • Безымянный — 7-й лад 4-й струны.
  • Мизинец — 7-й лад 3-й струны.
  • Средний — 6-й лад 2-й струны.
  • Не играть: 6.
Вариант 3
  • Указательный лежит поперёк струн с 6-й по 1-ю на 10-м ладу (баррэ).
  • Безымянный — 12-й лад 5-й струны.
  • Мизинец — 12-й лад 4-й струны.

Нажмите на схему, чтобы услышать аккорд. Голубые точки — тоника, нота ре.
