Аккорд Fm на гитаре

Фа, минорный аккорд. Ноты: F (фа), G# (соль-диез), C (до).

Основной вариант
  • Указательный лежит поперёк струн с 6-й по 1-ю на 1-м ладу (баррэ).
  • Безымянный — 3-й лад 5-й струны.
  • Мизинец — 3-й лад 4-й струны.
Вариант 2
  • Указательный лежит поперёк струн с 5-й по 1-ю на 8-м ладу (баррэ).
  • Безымянный — 10-й лад 4-й струны.
  • Мизинец — 10-й лад 3-й струны.
  • Средний — 9-й лад 2-й струны.
  • Не играть: 6.

Нажмите на схему, чтобы услышать аккорд. Оранжевые точки — тоника, нота фа.
