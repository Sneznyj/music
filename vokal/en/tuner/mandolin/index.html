Mandolin tuning

The mandolin is tuned like a violin — G D A E — but the strings come in pairs: two strings per note, tuned in unison.

  • 4th string — G3, 196 Hz
  • 3rd string — D4, 293.66 Hz
  • 2nd string — A4, 440 Hz
  • 1st string — E5, 659.26 Hz

How to tune a mandolin online

  • Press "Turn on microphone" and allow access — the sound is processed right in your browser and never uploaded.
  • Pluck one string. The tuner recognises it and the needle shows how far it is below or above the note.
  • Needle left of centre — the string is flat, tighten the peg. Right — it is sharp, loosen it. The green zone (±5 cents) and a check mark mean the string is in tune.
  • Prefer tuning by ear? Tap a string in the list to hear its note.
  • Tune each string of a pair separately while muting the other with a finger, then play both — the beating should disappear.
