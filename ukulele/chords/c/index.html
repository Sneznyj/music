Аккорд C на укулеле

До, мажорный аккорд. Ноты: C (до), E (ми), G (соль).

Основной вариант
  • Безымянный — 3-й лад 1-й струны.
  • Открытые струны: 4, 3, 2.
Вариант 2
  • Указательный лежит поперёк струн с 2-й по 1-ю на 3-м ладу (баррэ).
  • Безымянный — 5-й лад 4-й струны.
  • Средний — 4-й лад 3-й струны.
