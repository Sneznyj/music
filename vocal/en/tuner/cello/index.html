Cello tuning

The cello is tuned in fifths C G D A — one octave below the viola.

  • 4th string — C2, 65.41 Hz
  • 3rd string — G2, 98 Hz
  • 2nd string — D3, 146.83 Hz
  • 1st string — A3, 220 Hz

How to tune a cello online

  • Press "Turn on microphone" and allow access — the sound is processed right in your browser and never uploaded.
  • Pluck one string. The tuner recognises it and the needle shows how far it is below or above the note.
  • Needle left of centre — the string is flat, tighten the peg. Right — it is sharp, loosen it. The green zone (±5 cents) and a check mark mean the string is in tune.
  • Prefer tuning by ear? Tap a string in the list to hear its note.
  • Start with the A string (220 Hz), then D, G and C.
  • Put your phone near the f-holes: low strings are heard better that way.

Frequently asked questions

What are the cello string frequencies?

C2 — 65.41 Hz, G2 — 98 Hz, D3 — 146.83 Hz, A3 — 220 Hz.

Will a laptop microphone work?

Yes, but for the lowest C place the cello closer or tune with a harmonic — the tuner understands it.
